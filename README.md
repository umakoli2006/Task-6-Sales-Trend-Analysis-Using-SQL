# Task 6: Sales Trend Analysis Using SQL

## Objective

Analyze monthly revenue and order volume using MySQL.

## Tools

* MySQL
* SQL
* MySQL Workbench

## SQL Concepts

* `SUM()` – Revenue
* `COUNT(DISTINCT)` – Order volume
* `GROUP BY` – Monthly grouping
* `ORDER BY` – Sorting
* `LIMIT` – Top 3 months
* `WHERE` – Time-period filtering
